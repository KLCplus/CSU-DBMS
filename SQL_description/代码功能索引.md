- [`InterfaceError`](../sdk/python/csudb.py#L96) — 接口层错误：驱动自身使用不当（如对已关闭连接发起请求、响应格式非法）。

- [`OperationalError`](../sdk/python/csudb.py#L117) — 操作错误：连接断开、认证失败等网络与运行环境问题（不应归咎于 SQL 本身）。
- [`IntegrityError`](../sdk/python/csudb.py#L122) — 完整性错误：主键/唯一约束、外键等约束被违反。
- [`InternalError`](../sdk/python/csudb.py#L127) — 内部错误：服务端内部故障，通常意味着服务端状态损坏。
- [`ProgrammingError`](../sdk/python/csudb.py#L132) — 编程错误：SQL 语法错、表不存在、占位符与参数个数不匹配等调用方错误。
- [`NotSupportedError`](../sdk/python/csudb.py#L137) — 不支持错误：驱动或服务端不支持请求的能力。
- [`_quote`](../sdk/python/csudb.py#L147) — 
- [`_bind`](../sdk/python/csudb.py#L165) — 
- [`_NativeConnection`](../sdk/python/csudb.py#L182) —

- [`request`](../sdk/python/csudb.py#L212) — 网络错误转 OperationalError，帧格式非法转 InterfaceError。
- [`Connection`](../sdk/python/csudb.py#L241) — 
- [`__init__`](../sdk/python/csudb.py#L254) — 成功后把服务端 attributes 存为 server_attributes，并以服务端确认的库名覆盖 database。

- [`server_info`](../sdk/python/csudb.py#L311) — 参数：无；返回服务端信息字典。走服务端 server_info 请求类型。

- [`__exit__`](../sdk/python/csudb.py#L354) — 原理：无论块内是否抛异常都调用 close，避免连接泄漏。
