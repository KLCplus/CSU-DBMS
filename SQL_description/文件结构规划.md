# SQL 模块文件结构规划（函数级）

本文档描述 `src/observer/sql` 目录的组织结构、职责划分，并细化到**每个文件中的关键类与函数**，用于指导 SQL 引擎功能的开发、维护与定位。

- 路径约定：文中所列文件路径均相对于 `src/observer/sql/`。
- 生成产物：`parser/lex_sql.cpp/.h` 与 `parser/yacc_sql.cpp/.hpp` 由 Flex/Bison 自动生成，不作为函数级说明对象；其源文件为 `parser/lex_sql.l` 与 `parser/yacc_sql.y`。

---

## 1. 总览

SQL 模块是一个典型的 **流水线式 SQL 引擎**：词法/语法分析 → 语义解析（名字/表达式绑定）→ 逻辑计划 → 规则优化 → 物理计划 → 执行。

```
src/observer/sql
├── parser/       词法分析、语法分析、语义解析（名字绑定）
├── stmt/         语句对象（AST 的面向对象表示）与语句工厂
├── expr/         表达式体系、元组（Tuple）、聚合器
├── operator/     逻辑算子 与 物理算子（执行算子）
├── optimizer/    逻辑/物理计划生成、重写与优化规则、Cascades 框架、统计信息
├── executor/     各类 SQL 语句执行器、结果集、执行阶段
├── plan_cache/   计划缓存
└── query_cache/  查询缓存
```

数据流：

```
SQL 文本
  → parser/parse_stage    （lex_sql.l + yacc_sql.y → parse_defs AST）
  → parser/resolve_stage  （expression_binder 名字/表达式绑定 → stmt/*）
  → optimizer/optimize_stage
       ├─ logical_plan_generator（stmt → operator/*_logical_operator）
       ├─ rewriter/各 rewrite rule（谓词下推、常量折叠等）
       └─ physical_plan_generator（逻辑算子 → operator/*_physical_operator）
  → executor/execute_stage （语句执行器 + 物理算子 → sql_result）
```

## 2. SQL 执行流水线（Stage 编排）

| 阶段 | 实现 | 关键函数 |
| --- | --- | --- |
| ParseStage | `parser/parse_stage.*` | `ParseStage::handle_request` |
| ResolveStage | `parser/resolve_stage.*` | `ResolveStage::handle_request` |
| OptimizeStage | `optimizer/optimize_stage.*` | `OptimizeStage::handle_request` → `create_logical_plan` → `rewrite` → `generate_physical_plan` |
| ExecuteStage | `executor/execute_stage.*` | `ExecuteStage::handle_request` / `ExecuteStage::handle_request_with_physical_operator` |
| PlanCacheStage（可选） | `plan_cache/plan_cache_stage.*` | — |
| QueryCacheStage（可选） | `query_cache/query_cache_stage.*` | `QueryCacheStage::handle_request` |

### 3.1 parser —— 词法 / 语法 / 语义解析

#### 3.1.1 解析入口与 AST 定义

| 文件 | 类/函数 | 说明 |
| --- | --- | --- |
| `parse.h` / `parse.cpp` | `parse()` | 语法解析总入口（`ParsedSqlResult::add_sql_node` 收集节点） |
| `parse_defs.h` | 各 AST 中间节点 | 见下方 |

`parse_defs.h` 定义的节点与枚举：

- **结构体（AST 节点）**：`RelAttrSqlNode`（表.列）、`ConditionSqlNode`（比较条件）、`JoinSqlNode`（显式 JOIN）、`SelectSqlNode`、`InsertSqlNode`、`DeleteSqlNode`、`UpdateSqlNode`、`AttrInfoSqlNode`（含 `nullable`）、`CreateTableSqlNode`、`DropTableSqlNode`、`AnalyzeTableSqlNode`、`CreateIndexSqlNode`、`DropIndexSqlNode`、`DescTableSqlNode`、`LoadDataSqlNode`、`SetVariableSqlNode`、`ExplainSqlNode`、`ErrorSqlNode`（`error_msg/line/column`）、`CalcSqlNode`。
- **枚举**：`CompOp`（`EQUAL_TO/LESS_EQUAL/NOT_EQUAL/LESS_THAN/GREAT_EQUAL/GREAT_THAN/IS_NULL/IS_NOT_NULL/NO_OP`）、`SqlCommandFlag`（`SCF_*`）。
- **类**：
  - `ParsedSqlNode`：`ParsedSqlNode()`（默认构造）、`ParsedSqlNode(SqlCommandFlag)`；承载 `flag` 与各语句节点联合体。
  - `ParsedSqlResult`：`add_sql_node()`（追加解析结果）、`sql_nodes()`（访问器）。

#### 3.1.2 词法/语法生成源

| 需求项 | 主要落点（文件:函数） |
| --- | --- |
| 词法分析（关键字/常量/运算符/注释/转义/位置） | `parser/lex_sql.l`（规则段 + `YY_USER_ACTION`） |
| 语法分析（优先级、括号、AST） | `parser/yacc_sql.y`、`parser/parse_defs.h` |
| 语义分析（表/列存在性、名字绑定、类型一致性） | `parser/expression_binder.*::bind_*`、`parser/resolve_stage.*::handle_request` |
| CREATE / INSERT / SELECT / DELETE / WHERE | `stmt/*_stmt.*::create`、`operator/predicate_physical_operator.*`、`operator/project_physical_operator.*` |
| 比较 / AND / OR / NOT / 括号 | `expr/expression.*`（`ComparisonExpr::compare_value`、`ConjunctionExpr::get_value`）、`parser/yacc_sql.y` |
| UPDATE、ORDER BY、GROUP BY、JOIN | `stmt/update_stmt.*`、`operator/sort_physical_operator.*`、`operator/*group_by*`、`operator/*join*` |
| 算术表达式 | `expr/arithmetic_operator.hpp`、`expr/expression.*::ArithmeticExpr` |
| NULL（三值逻辑、IS [NOT] NULL、聚合跳过 NULL） | `expr/expression.*`、`expr/aggregator.*`、`expr/tuple.h::RowTuple`、`storage/table/table*`、`storage/field/field_meta.*` |
| 常量折叠 / 布尔化简 / 谓词下推 | `optimizer/arithmetic_simplification_rule.*`、`optimizer/conjunction_simplification_rule.*`、`optimizer/predicate_pushdown_rewriter.*` |
| EXPLAIN / 索引扫描 / 代价模型 | `operator/explain_physical_operator.*`、`operator/index_scan_physical_operator.*`、`optimizer/cascade/cost_model.*` |
| 计划生成 | `optimizer/logical_plan_generator.*::create_plan`、`optimizer/physical_plan_generator.*::create_plan` |
