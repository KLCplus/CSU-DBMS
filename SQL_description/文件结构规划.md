# SQL 模块文件结构规划（函数级）

本文档描述 `src/observer/sql` 目录的组织结构、职责划分，并细化到**每个文件中的关键类与函数**，用于指导 SQL 引擎功能的开发、维护与定位。

- 路径约定：文中所列文件路径均相对于 `src/observer/sql/`。
- 生成产物：`parser/lex_sql.cpp/.h` 与 `parser/yacc_sql.cpp/.hpp` 由 Flex/Bison 自动生成，不作为函数级说明对象；其源文件为 `parser/lex_sql.l` 与 `parser/yacc_sql.y`。

---

## 1. 总览

SQL 模块是一个典型的 **流水线式 SQL 引擎**：词法/语法分析 → 语义解析（名字/表达式绑定）→ 逻辑计划 → 规则优化 → 物理计划 → 执行。

```
src/observer/sql
├── parser/       词法分析、语法分析、语义解析（名字绑定）
├── stmt/         语句对象（AST 的面向对象表示）与语句工厂
├── expr/         表达式体系、元组（Tuple）、聚合器
├── operator/     逻辑算子 与 物理算子（执行算子）
├── optimizer/    逻辑/物理计划生成、重写与优化规则、Cascades 框架、统计信息
├── executor/     各类 SQL 语句执行器、结果集、执行阶段
├── autocomplete/ SQL 输入补全（确定性 Parser+Catalog，可选 FIM 模型）
├── plan_cache/   计划缓存
└── query_cache/  查询缓存
```

> 配套资源：`unittest/observer/autocomplete_test.cpp`（补全单元测试）、`SQL_description/test/`（SQL 编译器与基础功能自动化测试集）、`etc/sql_completion.json`（补全配置）、`scripts/build_llama_p40.sh` 与 `scripts/run_sql_completion_model.sh`（模型构建/启动）。

数据流：

```
SQL 文本
  → parser/parse_stage    （lex_sql.l + yacc_sql.y → parse_defs AST）
  → parser/resolve_stage  （expression_binder 名字/表达式绑定 → stmt/*）
  → optimizer/optimize_stage
       ├─ logical_plan_generator（stmt → operator/*_logical_operator）
       ├─ rewriter/各 rewrite rule（谓词下推、常量折叠等）
       └─ physical_plan_generator（逻辑算子 → operator/*_physical_operator）
  → executor/execute_stage （语句执行器 + 物理算子 → sql_result）
```

### 3.1 parser —— 词法 / 语法 / 语义解析

#### 3.1.1 解析入口与 AST 定义

| 文件 | 类/函数 | 说明 |
| --- | --- | --- |
| `parse.h` / `parse.cpp` | `parse()` | 语法解析总入口（`ParsedSqlResult::add_sql_node` 收集节点） |
| `parse_defs.h` | 各 AST 中间节点 | 见下方 |

`parse_defs.h` 定义的节点与枚举：

- **结构体（AST 节点）**：`RelAttrSqlNode`（表.列）、`ConditionSqlNode`（比较条件）、`JoinSqlNode`（显式 JOIN）、`SelectSqlNode`、`InsertSqlNode`、`DeleteSqlNode`、`UpdateSqlNode`、`AttrInfoSqlNode`（含 `nullable`）、`CreateTableSqlNode`、`DropTableSqlNode`、`AnalyzeTableSqlNode`、`CreateIndexSqlNode`、`DropIndexSqlNode`、`DescTableSqlNode`、`LoadDataSqlNode`、`SetVariableSqlNode`、`ExplainSqlNode`、`ErrorSqlNode`（`error_msg/line/column`）、`CalcSqlNode`。
- **枚举**：`CompOp`（`EQUAL_TO/LESS_EQUAL/NOT_EQUAL/LESS_THAN/GREAT_EQUAL/GREAT_THAN/IS_NULL/IS_NOT_NULL/NO_OP`）、`SqlCommandFlag`（`SCF_*`）。
- **类**：
  - `ParsedSqlNode`：`ParsedSqlNode()`（默认构造）、`ParsedSqlNode(SqlCommandFlag)`；承载 `flag` 与各语句节点联合体。
  - `ParsedSqlResult`：`add_sql_node()`（追加解析结果）、`sql_nodes()`（访问器）。

#### 3.1.2 词法/语法生成源

| 文件 | 关键点 |
| --- | --- |
| `lex_sql.l` | Flex 源：关键字/标识符/常量/运算符规则（含 `OR`）、`%x COMMENT` 多行注释状态、字符串转义（`''`/`""`/`\x`）、`%option yylineno` + `YY_USER_INIT`/`YY_USER_ACTION` 输出 **1-based 跨行行列**、`scan_string()` 绑定输入。生成 `lex_sql.cpp/.h`（`yylex` 等）。 |
| `yacc_sql.y` | Bison 源：文法与优先级（`%left/%precedence`，`OR < AND < 比较 < NOT`）、`%define parse.error custom` + `yyreport_syntax_error()`（位置 + unexpected + expected）、`unescape_quoted_string()`、`create_arithmetic_expression()`、`create_aggregate_expression()`、`set_expr_name_and_location()`、`append_join_node()`、`collect_expected_tokens()`（补全复用期望集合）。生成 `yacc_sql.cpp/.hpp`（`yyparse`）。 |
| `expected_tokens.h` | `collect_expected_tokens()` 声明：在 SQL 前缀末尾追加哨兵，复用 bison 期望集合，供自动补全使用。 |
