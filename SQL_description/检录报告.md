# 检录报告：SQL 编译器需求对照检查

- 检查对象：`src/observer/sql/`（OceanBase Miniob 课程代码库）+ SQL 输入补全 `src/observer/sql/autocomplete/`
- 对照文档：`SQL_description/requirements.md`（SQL 编译器需求拆解）
- 检录日期：2026-09-14（更新）
- 结论概览：**必备能力、进阶能力、词法/语法/语义分析的关键要求均已实现**。本阶段补齐了上一版列出的全部堵点（字符串转义、投影裁剪、语义错误定位、INSERT 逐列 TypeMismatch、类型一致性严格校验、语法 `expected:` 集合），并修复了若干基础缺陷（词法器缺 OR、NOT 优先级写反、标识符大小写敏感、空字符串崩溃、多余右括号误接受等）。此外新增 **SQL 输入自动补全（确定性 Parser+Catalog，可选 Qwen2.5-Coder FIM）** 与 **自动化测试集**（`SQL_description/test/`）。

## 十、本轮修复的基础缺陷

1. **词法器缺少 `OR`**：`Or` 被当作 `ID`，导致 `a=1 or b=1` 结果错误、`(a=1 or b=1)` 语法错误 → `lex_sql.l` 补 `OR`。
2. **NOT 优先级写反**：`not a=1 and b=1` 被解析为 `not (a=1 and b=1)` → 重排 `%left/%precedence`。
3. **标识符大小写敏感**：`SELECT A FROM P` 报字段/表不存在 → `Db::find_table`、`TableMeta::field` 改为 `strcasecmp`。
4. **空字符串字面量崩溃**：`insert ... values ('')` SEGV → `Value::set_string_from_other` 空串深拷贝 + `Table::set_value_to_record` 空指针保护。
5. **多余右括号被接受**：`where a=1);` 执行成功 → `ParseStage` 检查全部解析节点，任一条报错即反馈。
6. **一元负号 `-a`**：绑定/执行/迭代器空右操作数崩溃 → `expr/expression.cpp`、`expr/expression_iterator.cpp` 判空。
7. **NOT 布尔比较恒为 false**：`BOOLEANS` 走未实现的 `DataType::compare` → `Value::compare` 特判 BOOL。
8. **GROUP BY 遇 NULL 崩溃**：`Value::compare` 未处理 NULL → 增加三值逻辑。
9. **UPDATE 无法把 NULL 字段更新为值**：未同步 NULL 位图 → `update_physical_operator.cpp` 维护位图。
10. **OR 被优化器拒绝**：`PredicatePushdownRewriter` 对 OR 返回 `UNIMPLEMENTED` → 保留在 Predicate 中执行。
