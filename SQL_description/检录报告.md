## 八、关键堵点汇总（建议优先补齐）

1. **字符串转义**：`Tom''s` 连续引号未支持（`lex_sql.l` 的 `%x STR` 状态未用）。
2. **投影裁剪**：无 Projection Pruning / Project[*] 消除规则。
3. **语义错误定位**：表达式已带行列，但语义错误响应未结构化输出。
4. **INSERT 逐列 TypeMismatch 报告**：已逐列校验，未结构化报告。
5. **类型一致性**：`INT+VARCHAR` 等算术类型错误未严格报错。
6. **语法 `expected:` 集合**：未输出期望符号集合。
